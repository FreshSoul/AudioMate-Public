# AudioMate 用户使用指南

AudioMate 是以Wwise链接为基础面向游戏音频项目的 AI 助手桌面应用。它可以通过 WAAPI 连接正在运行的 Wwise，帮助你查询工程对象、分析音频响度、整理项目资料、生成或执行可确认的自动化操作，并支持自定义知识库、Skill 和 MCP 工具扩展以控制引擎与DAW。

## 适合用来做什么

- 用自然语言操作 Wwise 工程中的一切内容。
- 对Wwise内一切内容做音频相关分析，生成可读报告。
- 上传项目规范、音频设计文档、表格、PDF 等资料，让回答参考你的团队知识库。
- 通过 Skill 固化常用工作流，让 Agent 在特定任务中按既定规则工作。
- 接入 MCP 配置，把外部系统或团队工具加入对话流程。

## 使用前准备

### 1. 准备 Wwise

1. 打开你的 Wwise 工程。
2. 确认 Wwise 已启用 WAAPI，并允许本机连接。
3. 默认端口号为8080。

如果 AudioMate 显示无法连接，通常是 Wwise 未启动、WAAPI 未开启，或端口被防火墙/安全软件拦截。

### 2. 准备模型密钥

AudioMate 使用兼容 OpenAI 接口的模型服务。首次使用前需要在应用内保存：

- `Base URL`：模型服务地址。
- `API Key`：你的访问密钥。

打开 `Settings` > `令牌密钥`，填写后点击 `保存密钥`。请不要把真实密钥发给他人，也不要写入公开文档或截图。

## 启动 AudioMate

### 使用发布包

如果你拿到的是发布包，进入发布目录后双击 `AudioMate.exe` 即可启动。


## 主界面说明

### 左侧 Workspace

- `New Chat`：开始新对话。
- 历史列表：切换之前的对话记录。
- `Knowledge`：管理个人知识库。
- `Settings`：配置账户、密钥、Skill、MCP 等。
- 左上角菜单按钮：折叠或展开侧边栏。

### 顶部状态栏

- `Wwise` 状态：显示当前是否连接到 Wwise。
- `Connect`：连接或断开 Wwise。
- `Mode`：切换 `Ask Mode` 和 `Agent Mode`。
- `Theme`：切换浅色/深色主题。

### 底部输入区

- 文本框：输入你想让 AudioMate 完成的任务。
- 模型选择器：选择本轮使用的模型。
- 知识库选择器：选择要参考的个人知识库。
- Skill 选择器：选择自动匹配 Skill，或固定加载某个已启用 Skill。
- 语音按钮：调用 Windows 语音输入能力。
- 发送按钮：提交当前消息。

输入框支持拖入或粘贴图片、文件路径和本地文件。AudioMate 会在对话中把这些内容作为上下文使用。

## 两种工作模式

### Ask Mode

Ask Mode 适合查询、解释、分析和生成建议。它允许自动执行只读操作，但会阻止写入项目的操作。

适合的问题：

- “帮我列出当前选中对象，并总结开发规律。”
- “分析当前选中音频的响度，评价频段，告诉我哪些可能过响。”
- “解释这个 Sound SFX 的路由和关键属性。”

### Agent Mode

Agent Mode 适合需要改动项目数据的任务。它可以执行更完整的自动化流程，但涉及写入、覆盖文件或修改 Wwise 时，应先检查确认界面中的操作内容。

适合的问题：

- “把当前选中 Sound 的音量统一设置为经所有路由后响度-18Lufs-i。”
- “为这些 Footstep 随机化 Pitch，范围控制在 -50 到 50 cents。”
- “根据这份表格批量整理对象备注、设置。”

可在 Ask Mode 中让 AudioMate 解释计划，再切到 Agent Mode 执行实际修改。

## 典型使用流程

### 连接 Wwise 并提问

1. 打开 Wwise 工程。
2. 启动 AudioMate。
3. 点击顶部 `Connect`。
4. 在 Wwise 中选中你要处理的对象。
5. 在 AudioMate 输入任务，例如：

```text
分析当前选中对象下所有源文件的响度，并按风险从高到低列出结果。
```

### 使用知识库

1. 点击左侧 `Knowledge`。
2. 点击 `新建知识库`，输入名称。
3. 点击 `上传文档`，选择 `TXT`、`MD`、`PDF`、`Word`、`Excel`、`PPT` 等文件。
4. 回到聊天页，在底部知识库选择器中选择该知识库。
5. 提问时说明你希望参考资料，例如：

```text
参考项目音频规范，检查当前选中对象的命名和响度是否符合要求。
```

### 使用 Skill

Skill 用来定义 Agent 的专门能力和行为。适合把团队常用流程、检查清单或自动化规则打包成可复用能力。

1. 打开 `Settings`。
2. 在 `Skill（技能）` 区域点击 `新增 Skill`。
3. 选择本地 Skill 目录。
4. 启用导入后的 Skill。
5. 回到聊天页，在 Skill 选择器中保持 `Auto Skill`，或手动指定某个 Skill。

如果你通过浏览器中的 Skill Hub 点击“一键 AudioMate”，系统会通过 `audiomate://` 协议把 Skill 发送到当前 AudioMate 窗口。若 AudioMate 是被冷启动打开的，需要回到浏览器再点击一次导入按钮。

### 使用 MCP

MCP 配置用于连接外部工具或团队系统。

1. 打开 `Settings`。
2. 在 `MCP 配置` 中点击 `新建配置`。
3. 填写配置名称。
4. 粘贴 MCP JSON 配置。
5. 点击 `保存配置`，并在 `当前配置` 中选中它。

示例结构：

```json
{
  "transport": "streamable_http",
  "url": "http://127.0.0.1:8000/mcp",
  "headers": {}
}

## 数据与安全建议

- 修改 Wwise 项目前，建议先保存工程或使用版本管理。
- 对写操作保持确认习惯，尤其是批量修改、导入、删除、覆盖文件等任务。
- Ask Mode 默认限制写操作，适合探索和检查。
- 不要在聊天、知识库或 Skill 中放入不该暴露的密钥、账号密码或内部凭证。
- 本地文件授权后，AudioMate 才能读取相关文件内容；大文件可能会被截断处理。

## 常见问题

### 无法连接 Wwise

- 确认 Wwise 正在运行。
- 确认 Wwise 的 WAAPI 已启用。
- 确认本机 `127.0.0.1:8080` 未被防火墙或其他程序阻断。
- 重新点击 `Connect`，必要时重启 Wwise 和 AudioMate。

### 模型没有响应或提示鉴权失败

- 打开 `Settings` > `令牌密钥`，检查 `Base URL` 和 `API Key`。
- 确认密钥仍有效，且模型服务支持当前选择的模型。
- 切换到另一个模型再试。

### 知识库没有被参考

- 确认底部知识库选择器已选中目标知识库。
- 确认文档已上传到该知识库。


### Agent Mode 没有执行修改

- 确认当前模式是 `Agent Mode`。
- 确认 Wwise 已连接。
- 查看是否有确认卡片、权限提示或错误信息需要处理。
- 如果任务描述含糊，可先让 AudioMate 生成计划，再要求执行。


## 更新与反馈

在 `Settings` 中可以查看账户、检查更新、打开发布页。主界面顶部也提供反馈入口，遇到连接、模型、知识库或自动化执行问题时，可以附上问题描述和必要的截图。
